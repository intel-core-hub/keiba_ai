# 名古屋大学 多元数理科学研究科 院試対策（1次・現行日目形式）

元資料「4分野別 優先問題リスト（対名大多元数理）」をもとに、**優先問題だけを抽出したリスト**と、その**解答集**をまとめたフォルダです。

## 収録ファイル

| ファイル | 内容 |
|----------|------|
| [`優先問題リスト.md`](./優先問題リスト.md) | 4分野（解析・線形代数・複素関数論・位相）×18型を優先度別に抽出。第1グループ（土台 ★最・◎）／第2グループ（上積み ○）／「無理してでもやるべき追加問題」／「切ってよい」を整理 |
| [`優先問題_解答集.md`](./優先問題_解答集.md) | 各型の代表問題を標準形で再構成し、完全解答と「型のポイント（まとめノート用の言語化）」を収録 |

## 使い方

1. `優先問題リスト.md` で**今日やる型**を決める（まずは土台8型）。
2. `優先問題_解答集.md` で該当型の**代表問題を1問通し**、末尾の「この型のポイント」を自分のまとめノートに写経する。
3. 本番では「これは○○の型」と判定 → 型の第一手を出す。解答集末尾の「付録：本番での回し方」を直前に見返す。

## 優先度マップ（要約）

- **確実に回収する土台**：解析①②③ / 線形①②③ / 複素① / 位相①
- **差がつく上積み**：解析④⑤ / 線形④⑤ / 複素②③ / 位相②〜⑤
- **無理してでも追加**：複素②（7/23の唯一の穴）/ 位相②（網羅の一環）/ 解析⑤（他分野の前段道具）
- **切ってよい**：PDE・熱核 / 行列式単独・交代行列 / 距離空間の専門技法（§3.3〜3.5）

## 注記

解答集の各問題は、元資料に記された各年度の問題の **“型（テーマと関数・設定）”** に基づく**標準的な代表問題を再構成**したものです（過去問の原文そのものではありません）。狙いは「代表問題を1問通しておけば、本番で同型の初見問題に当てはめて解ける」状態を作ることです。
